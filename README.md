Model-free photo geolocator: reads each photo's JPEG DC colour, places yellow-marked roads in the Americas and everything else at the OSV-5M haversine centre (57, 28). No model calls, no API key.

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8080 python3 -P -s main.py
```
